# Noor Al-Quran — World-Class Holy Quran Web Application

Designed & Developed by Eng. Yahya Nabil

https://github.com/YahyaNabil

Version:
1.0.0

## Overview
Noor Al-Quran is a luxury, production-ready, highly accessible digital Quran experience combining sacred Islamic aesthetics with state-of-the-art web technology. Built with a refined palette of emerald green, deep obsidian black, brushed gold, and ivory, it offers an immersive spiritual and reading environment.

## Features
- Complete Holy Quran: 114 Surahs with customizable Arabic typography (Uthmani, Amiri, Scheherazade).
- Advanced Search & Navigation: Instant filtering by Surah, Verse, Page, and Juz.
- Audio Recitation: Multi-reciter audio streaming with synchronized verse highlighting and continuous playback.
- Spiritual Tools: Interactive Qibla Compass, digital Tasbeeh counter, daily Hadith, and accurate Prayer Times.
- Personalization: Bookmarks, notes, reading history, custom themes (Dark/Light/Emerald), and adjustable font scaling.
- PWA Ready: Offline support, caching, and installable web app capabilities.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript (ES6+ modular architecture)
- CSS Custom Properties & Glassmorphism UI
- Al Quran Cloud API / Local Fallback
